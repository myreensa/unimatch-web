# UniMatch

UniMatch is a personal hobby project exploring a different approach to online dating:

> **One match at a time.**

The idea is to encourage meaningful connections by preventing users from endlessly swiping and opening multiple new conversations while already getting to know someone.

## Current version

This is an early frontend prototype built with:

- HTML
- CSS
- JavaScript
- Browser localStorage

It currently demonstrates:

- Welcome screen
- Profile creation
- Discovering profiles
- Like / pass
- One active match at a time
- Match screen
- Chat prototype
- Ending a match
- Responsive mobile-first UI

## Important

This is **not yet a real multi-user dating service**.

User data and messages are stored only in the local browser. The next major step is adding a real backend, authentication, database, photo storage, and real-time chat.
